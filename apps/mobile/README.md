# @fiyatucuz/mobile

FiyatUcuz mobile application. React Native + Expo (SDK 52), Expo Router, TypeScript strict.

**Foundation state:** placeholder home screen. No product UI, no API integration.

## Local run

```bash
pnpm --filter @fiyatucuz/mobile start
```

Use the Expo Go app (or a simulator/emulator) to open the printed URL.

## Notes

- Expo `newArchEnabled: true` (Fabric + TurboModules).
- App scheme: `fiyatucuz://`.
- iOS bundle id / Android package: `com.fiyatucuz.app`.
